Privacy Policy

Last updated: October 2026

1. Information We Collect

This application does not store, log, or transmit any personal data. All marks and names you enter are processed in-memory on the server during a single request and are discarded immediately after the results page is rendered.

2. Cookies

We do not set any cookies or use any tracking technologies.

3. Third-Party Services

Bootstrap CSS is loaded from a CDN (cdn.jsdelivr.net). That CDN may log standard HTTP request metadata (IP address, user-agent) under its own privacy policy.

4. Data Security

Because no data is persisted, there is no stored data at risk. If you choose to deploy this application with HTTPS, all data in transit is encrypted.

5. Changes

We may update this policy. Changes will be reflected on this page with a revised date.

6. Contact

For questions, contact the project maintainer through the project repository.
